### 気づき・疑問

1. **今回の設定ではFlash-Liteの待ち時間が短かった。**
   質問ごとの中央値を比べると、Flashの所要時間はFlash-Liteの約3.9〜5.7倍だった。
   特に短い説明では平均出力が61対60トークンとほぼ同じでも、時間には差があった。
   Flashには平均約1,301の思考トークンが記録されているため、本文の長さだけでは待ち時間を説明できない。
   ただし、この実験では思考を無効化した対照条件を設けておらず、時間差がすべて思考によるものとは断定できない。
2. **詳しい説明は、短い説明より両モデルとも時間がかかった。**
   比較説明の平均出力は約408〜415トークンで、短い説明の約60〜61トークンより多かった。
   応答時間の中央値もFlash-Liteで1.419秒から2.744秒、Flashで8.023秒から10.630秒に増えた。
   入力の長さ・質問内容も同時に変えているので、出力トークン数だけの効果を測ったものではない。
3. **時間をかけても、渡していない講座情報が得られるとは限らなかった。**
   講座固有の質問は両モデルとも3回すべて「分からない」と回答し、Flashでは確認先の案内も付く傾向があった。
   正しいルールを回答させるには、用語集などの情報を渡す設計が必要だと考えた。
4. **回答の大筋は似ていても、表現には違いがあった。**
   LoRAの説明では元モデルを維持して追加学習するという方向は共通していた。
   比較説明も、外部知識の参照とモデルの振る舞いの調整を対比していたが、断定の強さや文章量は異なった。
   今回は人手で本文を確認しただけで、採点基準を設けた品質評価はしていない。

### レート制限との関係

Gemini APIの代表的な制限はRPM（毎分リクエスト数）、TPM（毎分の入力トークン数）、
RPD（1日あたりのリクエスト数）。どれか1つを超えてもエラーになり、APIキー単位ではなく
プロジェクト単位で適用される。モデルや利用階層によって上限が異なり、
実際の値はAI Studioで確認する必要がある。
出典：[Gemini APIのレート制限](https://ai.google.dev/gemini-api/docs/rate-limits)
（2026-10-20参照）。

今回は各応答の後に30秒待ち、並列実行もしていないため、実験全体の呼び出し頻度は毎分2回未満になる。
この実行では429は発生しなかった。比較実験は各モデル9回、入力トークンは各モデル合計300で、
動作確認では別にFlash-Liteを3回呼び出した。
入力は短いが、長い資料を質問に含めるようにすると、呼び出し回数が同じでもTPMが制約になりうる。
一方、待機間隔を延ばしても1日の総リクエスト数は減らないため、RPDに達した場合は回数を減らすか、
日次枠のリセットを待つ必要がある。「429なら1分待てば必ず解消する」とは限らない。

出力・思考トークンは入力TPMと区別する。長い回答や思考と応答時間の関係は観察できるが、
時間差だけから特定のレート制限に達したとは判断できない。
利用プロジェクトの利用階層・具体的なRPM/TPM/RPDの上限は未確認であり、
この実験だけで無料枠の限界値を推定したり、別の環境でも同じ間隔なら成功すると断定したりはできない。

### 比較の限界

- 各条件3回の小規模実験。通信状況やサービス側の負荷、初回接続、実行順の影響を分離していない。
- 同じtemperature・出力上限を指定しても、モデルごとの既定の思考動作や回答の長さは異なる。
  この条件での利用者から見た待ち時間を比べる実験であり、モデル内部の生成速度だけを比較したものではない。
- `thinking_tokens` が `null` の場合は「取得不可」と扱い、0とはみなさない。
  集計では欠測値を除外して取得件数を併記する。
- 成功は回答本文があることを意味し、内容の正しさを保証しない。終了理由が `MAX_TOKENS` の場合も
  成功集計には含まれるため、打切り件数と本文を別途確認する。
- 比較説明には、RAGがハルシネーションを「防ぐ」という断定的な表現もあった。
  このような記述の根拠確認は必要であり、速さやトークン数だけで回答品質の優劣は決められない。

### 再実行

リポジトリのルートで実行する。ローカルでは `--env-file .env` を指定する。
Codespaces secretなどで `GEMINI_API_KEY` を設定済みなら、このオプションは不要。
保存先は実行ごとに上書きするため、既存の結果を残す場合は別の名前を指定する。

```bash
uv run --env-file .env python -m scripts.benchmark run \
  --models gemini-3.5-flash-lite gemini-3.5-flash \
  --repeats 3 \
  --interval 30 \
  --temperature 1.0 \
  --max-output-tokens 2048 \
  --output lectures/01/results.jsonl

uv run python -m scripts.benchmark summarize lectures/01/results.jsonl
```
